# Social sharing card

Generated with the built-in imagegen tool, then exported at 1200×630 for social
previews. Final project asset: `assets/social-card.png`.

## Prompt

Use case: ads-marketing.
Asset type: social sharing / Open Graph card for a browser exploration game.
Primary request: Create a polished, wide 1200 x 630 pixel sharing image for SUBMARINE — DECK EXPLORER.
Scene: A long, minimal submarine corridor in a clean gray 3D blockout style. Plain matte walls, a level ceiling and floor, soft overhead lighting, and a bulkhead door with a circular porthole at the far end. The actual game is a restrained architectural blockout, so keep that honest visual style; do not invent detailed machinery or characters.
Composition: A full-bleed finished card, landscape aspect ratio 40:21. Strong perspective down the corridor. Give the title generous dark negative space and keep all important text at least 80 pixels inside every edge.
Typography: Large, exceptionally clear modern sans-serif title. Main line exactly "SUBMARINE"; smaller line exactly "DECK EXPLORER". No other words. Use restrained letter spacing and excellent legibility at thumbnail size.
Palette: charcoal navy, cool neutral gray, warm white, and the game's pale mint accent (#a8eed9).
Mood: quiet, atmospheric, inviting exploration. A subtle thin compass motif may complement the existing visual identity.
Constraints: no browser chrome, no UI screenshot, no movement buttons, no device mockup, no people, no weapons, no rust or extra props, no external logos, no watermark. Deliver only the finished rectangular share card with an opaque background.
